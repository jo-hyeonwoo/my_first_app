# 하단 네비게이션 바 UI 개선 및 기능 점검

## 작업 개요
하단 네비게이션 바의 가시성과 사용성을 개선하고, 모든 기능이 정상적으로 작동하는지 점검했습니다.

## 개선 사항

### 1. UI 개선

#### 스타일 개선
- **타입 설정**: `BottomNavigationBarType.fixed`로 설정하여 항상 모든 아이템이 표시되도록 개선
- **Elevation 추가**: `elevation: 8`로 설정하여 네비게이션 바가 화면 위에 떠 있는 느낌을 주어 가시성 향상
- **배경색 명시**: `backgroundColor`를 명시적으로 설정하여 테마와 일관성 유지

#### 색상 개선
- **선택된 아이템**: `selectedItemColor`로 primary 색상 사용
- **선택되지 않은 아이템**: `unselectedItemColor`로 onSurfaceVariant 색상 사용
- **명확한 대비**: 선택된 아이템과 선택되지 않은 아이템 간 명확한 시각적 구분

#### 텍스트 스타일
- **선택된 라벨**: `fontWeight: FontWeight.w600`으로 강조
- **선택되지 않은 라벨**: `fontWeight: FontWeight.w400`으로 일반 표시
- **폰트 크기**: `fontSize: 12`로 일관성 유지

#### 아이콘 개선
- **아이콘 크기**: `iconSize: 24`로 설정하여 적절한 크기 유지
- **아이콘 스타일**: 
  - 선택되지 않은 상태: outlined 아이콘 사용 (예: `Icons.home_outlined`)
  - 선택된 상태: filled 아이콘 사용 (예: `Icons.home`)
- **시각적 피드백**: 선택 상태에 따라 아이콘 스타일이 변경되어 현재 위치를 명확히 표시

#### 한글 라벨
- **홈**: "Home" → "홈"
- **성적**: "Scores" → "성적"
- **캘린더**: "Calendar" → "캘린더"
- **프로필**: "Profile" → "프로필"

### 2. 기능 점검

#### 라우팅 로직 개선
- `_locationToTabIndex` 함수 개선:
  - 정확한 경로 매칭 우선 처리
  - 경로 시작 부분 매칭으로 하위 경로 처리
  - 기본값을 홈(0)으로 설정하여 안전성 확보
  - 주석 추가로 코드 가독성 향상

#### 각 탭 기능 확인
1. **홈 탭** (`/home`)
   - ✅ 학생/선생님 역할에 따라 다른 화면 표시
   - ✅ 라우팅 정상 작동

2. **성적 탭** (`/scores`)
   - ✅ 성적 차트 및 리스트 표시
   - ✅ 라우팅 정상 작동

3. **캘린더 탭** (`/calendar`)
   - ✅ 캘린더 화면 표시 (현재 placeholder)
   - ✅ 라우팅 정상 작동

4. **프로필 탭** (`/profile`)
   - ✅ 사용자 정보 및 설정 메뉴 표시
   - ✅ 로그아웃 기능 연결
   - ✅ 라우팅 정상 작동

## 사용자 경험 개선

### 이전 문제점
- 네비게이션 바가 잘 안 보임
- 선택된 탭과 선택되지 않은 탭의 구분이 불명확
- 영어 라벨로 인한 사용성 저하

### 개선 효과
- ✅ 네비게이션 바 가시성 향상 (elevation, 색상 대비)
- ✅ 선택 상태 명확한 표시 (아이콘 스타일, 색상, 폰트 굵기)
- ✅ 한글 라벨로 사용성 향상
- ✅ 일관된 Material Design 3 스타일 적용
